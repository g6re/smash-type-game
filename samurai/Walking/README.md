# Caminar despacio

`east-sheet.png`: animación original del usuario, 17 fotogramas de 64 × 64.
Se reproduce al caminar hacia el este a velocidad baja, con ALT + WASD.
WASD sin ALT mantiene la velocidad de carrera y no usa este ciclo.
Cadencia inicial: 17 fps a velocidad 3, ajustada a la velocidad real.

Las otras direcciones conservan sus poses originales. No se refleja el este
para obtener el oeste, porque el personaje es asimétrico.
